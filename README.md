# Edge AI Monitor

A Raspberry Pi based edge-AI project for real-time object and person detection.

The goal of this project is to build a local computer vision system that processes camera input directly on the Raspberry Pi using AI acceleration.

## Current Status

The development environment is set up and ready for implementation.

Currently working:
- Raspberry Pi development environment
- Hailo AI accelerator
- Raspberry Pi Camera
- Picamera2
- Hailo Python API
- Remote development via SSH and PyCharm
- Git version control

## Planned Features

- Real-time camera input
- Person detection
- Object detection
- Hailo-accelerated AI inference
- Detection event logging
- System monitoring
- Simple dashboard for viewing detection statistics

## Hardware

- Raspberry Pi 5
- Raspberry Pi AI HAT / Hailo accelerator
- Raspberry Pi Camera
- Active cooling

## Software

- Python
- Raspberry Pi OS
- Picamera2
- Hailo AI software stack
- Git
- PyCharm Remote Development

## Project Goal

This project is being developed as a practical exploration of edge AI, computer vision, Linux and software development on embedded hardware.
